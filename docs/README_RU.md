**Верните контроль над своими рабочими процессами (workflows).**

Этот пакет пользовательских нод создает «Фейковые ноды» (имитации) для замены старых, удаленных или специфичных для облачных сервисов нод (таких как A1111, Cloud и т. д.), которые препятствуют загрузке рабочего процесса в ComfyUI.

> ⚠️ **ВАЖНО:** Эти ноды **НЕ обрабатывают изображения**. Это *заполнители* (placeholders), которые позволяют визуально загрузить граф без ошибок, сохраняя соединения (провода), чтобы вы могли заменить их функциональными нативными нодами.

---

## 🚀 Зачем это использовать?

Когда вы загружаете старый рабочий процесс и в нем отсутствуют ноды, ComfyUI часто ломает интерфейс или предотвращает выполнение.
Этот пакет решает проблему «курицы и яйца»:
1.  Загружает недостающие ноды как "Dummies" (пустышки).
2.  Позволяет вам видеть, куда шли провода.
3.  Дает возможность подключить нативные ноды (`Load Checkpoint`, `KSampler` и т. д.).
4.  После исправления вы можете удалить dummies.

## 🧑‍💻 Руководство разработчика: Как добавить больше нод

Структура спроектирована так, чтобы быть **модульной**. Если вы скачиваете новый поток и в нем отсутствует другая нода (например, `SuperUpscaler`), выполните следующие шаги, чтобы добавить ее в ваш локальный пакет:

### Шаг 1: Определение ноды
Откройте файл `nodes.py`. Скопируйте шаблон в конце и адаптируйте его. Важно определить `INPUT_TYPES` так, чтобы они соответствовали проводам, которые вам нужно спасти.

```python
# В nodes.py
class Fake_SuperUpscaler:
    def __init__(self): pass

    @classmethod
    def INPUT_TYPES(s):
        # Определите здесь входы, которые были у оригинальной ноды
        return {"required": { "image": ("IMAGE",), "scale": ("FLOAT", {"default": 1.5}) }}

    RETURN_TYPES = ("IMAGE",)
    FUNCTION = "do_nothing"
    CATEGORY = "Dummy Pack"

    def do_nothing(self, **kwargs): return (None,)
	```
	
### Шаг 2: Регистрация ноды
Откройте файл __init__.py, импортируйте ваш новый класс и добавьте его в сопоставление:

```python
# В __init__.py
from .nodes import Fake_ECHOCheckpointLoaderSimple, Fake_KSampler_A1111, Fake_SuperUpscaler # <--- 1. Импорт

NODE_CLASS_MAPPINGS = {
    "ECHOCheckpointLoaderSimple": Fake_ECHOCheckpointLoaderSimple,
    "KSampler_A1111": Fake_KSampler_A1111,
    "SuperUpscaler": Fake_SuperUpscaler # <--- 2. Сопоставить точное отсутствующее имя
}

NODE_DISPLAY_NAME_MAPPINGS = {
    "SuperUpscaler": "🛑 DUMMY SuperUpscaler" # <--- 3. Видимое имя в UI
}
```
### Шаг 3: Применение
Перезапустите ComfyUI и загрузите ваш поток. Готово!
